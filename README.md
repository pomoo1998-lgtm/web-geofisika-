# Website Eksplorasi Geofisika & Seismologi

Website interaktif edukasi geofisika berbahasa Indonesia yang mencakup:
- Pengantar Geofisika
- Simulasi Interaktif Gelombang Seismik (P-Wave & S-Wave)
- Kalkulator Estimasi Kedalaman Lapisan (Seismik Refraksi Sederhana)
- Kuis Kilat Geofisika

## Cara Deploy ke GitHub Pages:
1. Buat repository baru di GitHub (misal: `geofisika-web`).
2. Upload/Push file `index.html` dan `README.md` ini ke repository tersebut.
3. Masuk ke tab **Settings** di repository GitHub Anda.
4. Pilih menu **Pages** di sidebar kiri.
5. Pada bagian **Build and deployment**, ubah branch dari `None` menjadi `main` (atau `master`) dan folder `/ (root)`, lalu klik **Save**.
6. Website Anda akan online dalam beberapa menit!
